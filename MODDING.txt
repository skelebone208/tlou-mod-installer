TLOU MOD INSTALLER - MAKING MODS
================================
Free to use, share and build on. Works with The Last of Us Part I (PC) and
The Last of Us Part II Remastered (PC).

WHAT THE INSTALLER DOES
-----------------------
The games keep their files inside big .psarc archives in build\pc\main.
The first time a mod needs a file from one of those archives, the installer
unpacks that archive once into loose files and renames it to .psarc.bak, so
the game loads the loose files instead. Then it copies the mod's files in.

Small archives (steam.psarc, epic.psarc - the Steam and Epic Extras skins)
are different: the game only offers their content when the archive itself is
there. For those the installer still unpacks once (to patch the files), but
then rebuilds the archive with the mod's changes after every install and
uninstall, so the game finds it where it expects it. The untouched original is
kept as .psarc.bak.

Uninstall puts the original files back. They come straight from the game's own
.bak archive, so nothing is lost even if you installed files by hand before.
"Restore original game" removes every mod, deletes the unpacked files and
renames the archives back. Everything the installer records is kept in
build\pc\main\_modinstaller.

If Steam's "Verify integrity of game files" is used, Steam may re-download the
archive. Use "Restore original game" first, or just reinstall your mods after.

MOD LAYOUT (recommended)
------------------------
  My Mod.zip
    mod.json
    README.txt                 (optional)
    files\
      actor97\joel-head-01-u1-g1-v1.pak
      texturedict3\something.pak
      ...

Everything inside "files" mirrors the game's build\pc\main folder.

mod.json:
  {
    "format": 1,
    "id": "my-mod",            <- short unique name, used to uninstall later
    "name": "My Mod",
    "version": "1.0",
    "author": "you",
    "game": "tlou1",           <- "tlou1" = Part I, "tlou2" = Part II
    "description": "What it does"
  }

Files that only exist in one store's copy of the game (Steam-only or
Epic-only skins) can be listed as optional - they're skipped, not added, when
the game doesn't have them:
    "optional": ["actor97/ellie-costume-01-steam-mats.pak",
                 "actor97/ellie-costume-01-epic-mats.pak"]
Textures whose id isn't in the game are skipped the same way.

Keep the same "id" in new versions: installing a new version over an old one
updates it (and puts back any files the new version no longer changes).

WITHOUT A mod.json
------------------
Mods without a mod.json still install. The installer works out where each
file goes:
  - paths containing build\pc\main\... are used from there,
  - folders the game uses (actor97, texturedict3, pak68, ...) are kept,
  - a single file is matched by name against the game's files.
Readme files and pictures are ignored. Anything it can't place is skipped and
listed in the log. The zip's file name becomes the mod's name. To uninstall,
press "Installed mods", select it and press Uninstall.

SUPPORTED MOD FILES
-------------------
.zip and .rar work everywhere. .7z uses Windows' built-in tar.exe (newer
Windows 11) or 7-Zip if it's installed - .zip is the safest choice for sharing.
A single .pak file, or an unzipped mod folder (pick its mod.json), also works.

TEXTURES
--------
Character textures aren't separate files: the game streams them from big
texture dictionaries in build\pc\main\texturedict3, looked up by a 64-bit
texture id. To replace one, put a .tex file in a "textures" folder next to
"files" (the name doesn't matter, the id is inside):

  "NDTX" | u32 version (1) | u64 texture id | u32 DXGI format |
  u32 width | u32 height | u32 mip count | texture data...

The data must be laid out exactly as the game stores it (rows padded to 256
bytes, each mip level starting on a 512-byte boundary). The installer writes
it into every dictionary that holds that id and backs up the original. If the
texture is bigger than the game's slot, its largest mip levels are dropped
until it fits. Because the id stays the same, the new texture also shows in
the Extras skin viewer.

TWO MODS CHANGING THE SAME FILE
-------------------------------
The installer refuses and tells you which mod already changed that file.
Uninstall that one first.
